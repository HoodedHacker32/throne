# Throne app (all screens)

Mode: Operate. Visitor: a player or DM at a table or between sessions, on phone, tablet or laptop.
Job: run characters, write and find notes, run a campaign and combat.
Proof: real content only from the user's own data; sample content labelled sample.
Open: sync backend (Supabase org created, no project yet).

## Direction contract

THESIS: The category standard played straight: a D&D Beyond-style tabletop app, one task per screen, with separate Player and DM menus. It refuses the one crammed page.
OWN-WORLD: Charcoal chrome (#1b1b1b / #2a2a2a), parchment content panels (#f4efe2), Throne red (#ba0000) for primary action and active state only, ink (#14100e), bone text on dark. Condensed uppercase headings (Roboto Condensed), Metamorphous only for the logo and character/campaign names, Pirata One for large numerals. Square-ish 6 to 8px radii, thin keylines, tabbed panels.
STORY: A player opens the app, sees their party, taps a character, runs it (HP, rests, rolls, notes). A DM switches to the DM menu and runs the campaign, library and combat.
FIRST VIEWPORT: Phone: top bar with logo and Player/DM switch, party roster cards, bottom tab bar (Home, Sheets, Notes, Dice). Desktop: left rail replaces the tab bar, content panels centre, optional right panel. Primary action is red.
FORM: The category standard (canon) chosen on purpose by the user. seed: none (user-chosen canon of seed:d4454aba).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
