# Throne

Unofficial D&D Campaign Manager. Not affiliated with Wizards of the Coast.

- [PRODUCT.md](PRODUCT.md): who it is for and what it is
- [PLAN.md](PLAN.md): the build plan and milestones
- [docs/ddb-analysis.md](docs/ddb-analysis.md): research on D&D Beyond's builder, sheet and PDF export
- `brand/`: logo files and mockups
- `app/`: the app (Vite, React, TypeScript, Dexie for local storage)

## Run it

```powershell
cd app
npm install
npm run dev
```

## Status

M0 (foundation) and the start of M1 (notes) are in: local-first markdown notes with `[[wikilinks]]`, backlinks, tags, search, and an installable PWA shell. Characters, library, combat and dice are placeholders.
